# Vedanta Systems Privacy

Public Next.js privacy-policy website for Vedanta Systems Admin and Staff.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Production verification: `npm run build` then `npm start`.

## Deploy to Vercel

1. Push this project to a Git repository.
2. Import the repository in Vercel.
3. Keep the detected Next.js settings and deploy.
4. Configure the production domain and ensure HTTPS is active.
5. Complete the bracketed placeholders in `/privacy`, review `PRIVACY_AUDIT.md`, and obtain legal/technical approval before linking the URL in Google Play.

No environment variables, backend, or database are required.

## Content review

The policy intentionally uses placeholders rather than claims that cannot be verified from the source code. Update the date and all placeholders after completing the audit.
